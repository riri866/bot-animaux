Bot Discord : Quiz et duels d'Animaux

Un bot discord fait en python sur le théme des animaux avec quiz, combats et sauvegarde JSON.

Les fonctionnalités :
!quiz : Un quiz interactif à 5 questions pour ddécouvrir son animal totem

!duel : Combat au tour par tour entre joueur ou contre le bot

!info : Affiche le profil, l'animal totem et les stats

!liste : Catalogue des animaux du quiz et ceux des combats

!aide : Commande affichant l'integralité des  commande utilisable par les membres du serveur

Configuratrion et Lancement :

Dépendances : pip install discord.py python-dotenv

Variables (.env) : Ajouter DISCORD_TOKEN=votre_token


Lancement : python main.py
